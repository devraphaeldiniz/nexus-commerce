# Changelog

## [1.0.0-demo] - 2026-10-20

### Added

- Marketplace demonstrativo multi-vendedor.
- Autenticação OTP com sessão HttpOnly.
- Catálogo, carrinho, checkout e cálculo de frete.
- Escrow, ledger, disputas e fluxo logístico.
- Webhook Asaas autenticado e idempotente.
- Policies e testes de segurança.
- CI com build, testes, auditoria e artefato de cobertura.
- Workflow E2E de smoke test.
- OpenAPI, arquitetura, decisões técnicas e roteiro de demo.
- Seeder e comando `php artisan nexus:demo` para dados fictícios.

### Notes

Esta release é uma demonstração técnica. Integrações financeiras reais exigem credenciais, tokenização oficial do gateway e revisão operacional antes de produção.
